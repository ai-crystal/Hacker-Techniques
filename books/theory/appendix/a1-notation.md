# 附录 A　符号与术语

| 术语 | 说明 |
| --- | --- |
| PTE | 页表项。低 12 位是权限与状态位，其余是物理页帧号。 |
| TLB | 地址翻译缓存。命中则不必走四级页表，未命中会带来可观测的时间差。 |
| PLT / GOT | 动态链接的两张表。PLT 是跳转桩，GOT 存真实地址，延迟绑定让 GOT 在首次调用后才被填上。 |
| RELRO | 重定位只读。全开之后 GOT 不可写，部分开启只保护一部分节。 |
| chunk | glibc 分配器管理内存的基本单位，用户指针指向 chunk 头部之后 16 字节。 |
| tcache | 2.26 之后引入的每线程缓存，单链表，检查比 fastbin 少，是很多堆题的第一入口。 |
| unsorted bin | 刚被释放、尚未归类的 chunk 所在的双向链表，常用来泄漏 libc 地址。 |
| UAF | 释放后使用。指针未清空，内存已被复用。 |
| 原语 | 一类可复用的能力，如任意地址读、任意地址写、可控跳转。 |
| CFI | 控制流完整性。限制间接跳转只能落在预先算出的目标集合内。 |
| CET | Intel 的控制流强制技术，包含影子栈与间接分支跟踪。 |
| PAC | ARM 的指针认证，用密钥对指针签名，使用前验证。 |
| MTE | ARM 的内存标记扩展，给每块内存和每个指针打 tag，不匹配就报错。 |
| JIT | 即时编译。运行时生成机器码，因此需要可写可执行内存（W^X 下要靠双映射）。 |
| AEAD | 带关联数据的认证加密，一次运算同时给出密文和完整性标签。 |
| nonce | 一次性数值。同一密钥下重用 nonce 会直接毁掉 GCM 的安全性。 |
| KDF | 密钥派生函数。口令场景下要求慢，密钥场景下要求快且不可逆。 |
| 前向保密 | 长期密钥泄露不影响历史会话的机密性，靠每次握手生成临时密钥实现。 |
| 0-RTT | TLS 1.3 与 QUIC 的提前数据传输，代价是可重放。 |
| SNI | 握手里明文传输的服务器名称，中间人据此知道你要访问哪个域名。 |
| IDOR | 不安全的直接对象引用。把对象编号交给客户端，却没校验归属。 |
| SOP | 同源策略。源 = 协议 + 主机 + 端口，三者全同才算同源。 |
| CORS | 跨源资源共享。预检请求通过后，服务器用响应头声明允许的来源与方法。 |
| CSP | 内容安全策略。用响应头限制页面能加载与执行哪些资源。 |
| COOP / COEP | 跨源打开者策略与跨源嵌入者策略，用来把页面放进独立的进程与更严格的隔离。 |
| 符号执行 | 用符号代替具体输入执行程序，收集路径条件，交给求解器判断可达性。 |
| 抽象解释 | 在抽象域上计算程序状态的不动点，用保守近似换取可终止性。 |
| 覆盖率 | 模糊测试的反馈信号，常用边覆盖而非行覆盖。 |
| 基率 | 总体中正例的比例。它决定了同样的检测率与误报率下，报警的可信度。 |
| ROC / AUC | 以误报率为横轴、检出率为纵轴画出的曲线及其面积，与具体阈值无关。 |
