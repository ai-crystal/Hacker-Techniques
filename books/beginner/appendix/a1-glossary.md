# 附录 A　术语表

| 术语 | 说明 |
| --- | --- |
| ARP | 地址解析协议，把 IP 地址映射到局域网内的 MAC 地址。协议本身没有认证，谁回答都信。 |
| ASLR | 地址空间布局随机化。程序启动时随机偏移栈、堆、库的位置，让攻击者猜不准地址。 |
| canary | 栈保护符。编译器插在局部变量与返回地址之间的随机值，函数返回前检查是否被改动。 |
| C2 | 命令与控制。僵尸网络里攻击者向被控主机下发指令的通道。 |
| CVE | 公开漏洞的统一编号，格式为 CVE 加年份加序号。 |
| CVSS | 漏洞严重性评分，0 到 10 分，综合考虑利用难度与影响。 |
| DGA | 域名生成算法。恶意程序按算法批量生成候选域名，用来对抗域名查封。 |
| EDR | 端点检测与响应。在主机上持续采集行为数据并做出阻断或告警的安全产品。 |
| gadget | 程序里以 ret 结尾的一小段指令，ROP 利用的基本积木。 |
| Heartbleed | 2014 年 OpenSSL 心跳扩展的越界读漏洞，编号 CVE-2014-0160。 |
| JIT | 即时编译。运行时把字节码编译成机器码，需要可写可执行的内存。 |
| KDF | 密钥派生函数。把口令转换成密钥，通常故意设计得很慢。 |
| MITM | 中间人攻击。攻击者位于通信双方之间，可以窃听和篡改。 |
| NOP sled | 一串空操作指令。攻击者跳进这片区域后会自动滑到真正的载荷。 |
| NX | 不可执行位。标记某块内存可读可写但不可执行，用来阻止栈上执行代码。 |
| off-by-one | 差一错误。循环或多算一个字节，越界一个字节。 |
| POC | 概念验证代码，用来证明漏洞可被触发，通常不含完整利用。 |
| ROP | 返回导向编程。用程序自身的 gadget 串出任意逻辑，绕开不可执行内存。 |
| shellcode | 攻击者注入的一小段机器码，通常用来启动一个 shell。 |
| SSRF | 服务端请求伪造。让服务器代替攻击者去访问内网地址。 |
| setuid | 文件权限位。执行时把进程的有效用户号切换成文件所有者。 |
| TOCTOU | 检查与使用之间的时间差，竞态漏洞的典型形态。 |
| TLS | 传输层安全协议。为 TCP 连接提供加密与身份验证。 |
| UAF | 释放后使用。内存被释放后仍通过旧指针访问。 |
| XSS | 跨站脚本。把脚本注入到别人会浏览的页面里执行。 |
| CSRF | 跨站请求伪造。借用户已登录的凭据，在其不知情时发出请求。 |
| 0day | 厂商尚未发布补丁的漏洞。 |
| 提权 | 从低权限身份获取更高权限，通常是 root 或管理员。 |
| 沙箱 | 限制程序运行范围的隔离环境，出错时影响不外溢。 |
| 供应链攻击 | 通过篡改上游的软件、更新包或开发工具来感染下游用户。 |
