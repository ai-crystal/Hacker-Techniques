# 入门篇

> 从病毒史到攻防全景

你每天使用的电脑和手机，本质上是一台只会照做指令的机器。它不会分辨指令来自谁，也不会判断这条指令该不该执行。所谓的入侵，往往就是想办法让它执行一段原本不属于它的指令。

这一册从 1971 年的第一只病毒讲到 2026 年的勒索产业，再从晶体管、内存、系统调用一路讲到栈溢出、中间人攻击和供应链投毒。读完它，你不会立刻变成安全专家，但再看那些耸人听闻的新闻时，你能判断出危险究竟发生在哪一层。
