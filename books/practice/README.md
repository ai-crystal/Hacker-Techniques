# 实战篇

> 从靶场到真实对抗

从一台干净的虚拟机开始，搭隔离网络、装靶场、配工具链，然后在里面完成侦察、验证、利用、提权、横向和清理。每一章都有可复现的步骤和判断依据，不是命令清单。

后半册转向防守，讲样本分析、检测规则、日志狩猎和应急响应。攻击与防守用同一套实验环境，做完红队再做蓝队，才知道哪些告警真的有用。
