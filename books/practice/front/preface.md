# 前言　在自己搭的场子里练

先说一件必须说清楚的事。

这一册里的所有操作，都只应该在你自己的实验环境里做。虚拟机、隔离网络、自己买的域名、自己搭的靶场，这些随便折腾。别人的系统，哪怕只是“扫一下看看”，没有书面授权就是违法。这不是免责声明式的套话，很多国家的法律把“未经授权访问计算机系统”写得很宽，扫描端口都可能被算进去。

把这句话放在最前面，是因为下面的内容确实可以用在真实的系统上。工具本身没有立场，用在哪里有。

## 这一册怎么写

大多数实战教程给的是命令清单，第一步跑这个，第二步跑那个。照着做能出结果，但换一台机器就不灵了，因为不知道每一步在验证什么。

这一册尽量写成“判断加动作”的形式。每一节先说清楚目标是什么，当前掌握的信息够不够，然后给出动作，最后说明结果该怎么解读。命令只是动作的载体，版本变了、参数改了，判断逻辑还在。

书里的环境是固定的。一台 Kali 作为攻击机，一台 Ubuntu 作为跳板，一台 Windows Server 加一台 Windows 10 组成域环境，全部跑在同一台物理机的虚拟网络里。靶场用公开的 VulnHub 镜像、DVWA、Juice Shop 和几台自己配的机器。这些都能免费拿到，搭一次可以用很久。

## 四篇的顺序

第一篇准备环境和工具。这一篇看起来最没技术含量，实际上决定了后面能不能复现。快照、隔离、时钟同步这些细节，出问题的时候最耗时间。

第二篇打进去。Web 两章、二进制两章、内核一章。每一章都要求能解释清楚“为什么这个 payload 是这个长度”“为什么这个地址是这个值”，不能只贴结果。

第三篇横向与掌控。Windows 和 Active Directory 是企业环境的主战场，Kerberos、ACL、委派这些概念第一次看会很绕，书里会按攻击路径的顺序讲，而不是按协议文档的顺序。

第四篇换到防守。样本分析、检测规则、日志狩猎、应急响应。做完前三篇的攻击练习，你会知道自己留下的痕迹在哪里，这一篇就是把这些痕迹变成告警。

## 需要的准备

一台性能过得去的电脑，16 GB 内存起步，能同时跑三台虚拟机。装好 VMware 或 VirtualBox，准备好系统镜像。剩下的工具书里会一个个装，不需要提前配环境。

心态上要准备好花时间。堆利用那几节，第一次做可能要一整天，卡住是正常的。调试器里看到的和书上写的不一样，也正常，先怀疑自己的环境，再怀疑书。
