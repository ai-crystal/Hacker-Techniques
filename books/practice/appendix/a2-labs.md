# 附录 B　靶场与授权

练习必须在授权范围内进行。这一页列出的是公开的、明确允许练习的环境，以及获得授权的常见途径。

## B.1 本地靶场

- **DVWA**：PHP + MySQL，把注入、跨站、文件包含、命令注入各做成一个难度可调的模块。适合第一次动手，缺点是题目太典型，容易形成固定套路。
- **OWASP Juice Shop**：现代前端 + REST 后端，题目覆盖越权、JWT、SSRF、原型污染，难度梯度比 DVWA 自然。
- **OWASP WebGoat**：以课程形式组织，每个漏洞配一段解释，适合边学边打。
- **Metasploitable 2 / 3**：故意留有大量漏洞的 Linux 虚拟机，用来练扫描、利用与提权的基本流程。
- **VulnHub**：个人制作的靶机镜像，下载后本地运行。质量参差，挑评价多的。
- **自己编译的靶程序**：学二进制利用时最合适。关掉 canary、关掉 PIE 编一个几十行的程序，比任何成品靶场都直观。

## B.2 在线平台

- **Hack The Box**：机器与挑战两类，免费额度有限，界面成熟，适合练节奏。
- **TryHackMe**：以引导式房间为主，路径清晰，适合从零开始。
- **PortSwigger Web Security Academy**：免费，按漏洞类型组织的实验环境，讲得比多数付费课程清楚。
- **picoCTF**：面向学生，题目从入门到较难，长期开放。
- **GTFOBins / LOLBAS**：不是靶场，但提权时会反复查，收录了可用于绕过的系统二进制。

## B.3 域环境

- **GOAD（Game of Active Directory）**：用 Vagrant 或 Proxmox 一键搭多域环境，包含常见的错误配置。
- **自己搭**：一台 Windows Server 做域控，一台 Windows 10 加入域，再配一台文件服务器。三台虚拟机足够覆盖 Kerberoasting、ACL、委派这几类问题。

## B.4 样本分析

- **REMnux**：预装分析工具的 Linux 发行版。
- **FlareVM**：Windows 分析环境，装好反汇编、调试、监控工具。
- 公开样本库（如 MalwareBazaar、theZoo）里的样本只应在断网的虚拟机里打开，且不要上传到任何在线沙箱，除非你确认样本不含敏感信息。

## B.5 怎样算获得授权

- **书面授权**：渗透测试合同或授权书，写清目标范围、时间窗口、允许的手法、禁止的动作（如拒绝服务、社工）、联系人。
- **漏洞赏金计划**：项目页面上写明范围（scope）与规则，超出范围的一律不算授权。
- **自有环境**：自己买的云主机、自己的域名、自己的设备。注意云厂商的服务条款，有些默认禁止端口扫描。
- **学校或公司的演练**：需要有正式的演练通知与范围说明，口头同意不算。

没有上述任何一种，扫描别人的端口都可能违法。这一条没有灰色地带。
